I deleted the cluster and then remade it, here's the times I recorded:

5 minutes of downtime for the VM's from deleting, to re applying 

K8s API took 9 minutes to come back up 

ArgoCD Accessible 25 mins later, with password stored in OpenBao

Infrastructure fully synced - 28 mins later

Apps synced and accessable - 31 mins later


There were a few things I ran into an issue before getting to this point:

Issue where ArgoCD needs a secret to work but I didn't apply ArgoCD so ArgoCD can't apply its own secret from Git...

Let ArgoCD init it's own password then it will get overriden when the cluster is up.

---

Because I removed Longhorn from the terraform script and applied it with ArgoCD once the cluster is up, I needed to add these 2 manifests:
```bash
# Added this to longhorn-values
preUpgradeChecker:
  jobEnabled: false


# Applied these to the cluster
apiVersion: rbac.authorization.k8s.io/v1
kind: RoleBinding
metadata:
  name: longhorn-manager-binding
  namespace: longhorn-system
  annotations:
    argocd.argoproj.io/sync-wave: "-8"
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: Role
  name: longhorn
subjects:
  - kind: ServiceAccount
    name: longhorn-service-account
    namespace: longhorn-system
---
apiVersion: rbac.authorization.k8s.io/v1
kind: RoleBinding
metadata:
  name: longhorn-csi-role-binding
  namespace: longhorn-system
  annotations:
    argocd.argoproj.io/sync-wave: "-8"
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: Role
  name: longhorn-csi-role
subjects:
  - kind: ServiceAccount
    name: longhorn-csi-service-account
    namespace: longhorn-system
```
